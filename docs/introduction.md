# Introduction

discord-bot-rs is a multi-instance Discord bot framework written in Rust. Run one bot or many from a single codebase, each with its own personality, database schema, and feature set.

This documentation covers installation, configuration, features, architecture, deployment, and development. New users should start with [Getting Started](./getting-started/index.md). Contributors should start with [Development](./development/index.md).
